# Derleme bağımlılıkları

Büyük üçüncü taraf çalıştırılabilir dosyalar Git kaynaklarına eklenmez.
Gerekenler: `yt-dlp-fast/`, `yt-dlp`, `ffmpeg` ve Apple Silicon uyumlu `node`.

Mevcut Video İndir uygulamasındaki sürümleri aktarmak için:

```sh
bash tools/from-app.sh '/Applications/Video İndir.app'
```

Lisans ve sürüm bilgileri: [THIRD-PARTY.txt](../app/THIRD-PARTY.txt).
