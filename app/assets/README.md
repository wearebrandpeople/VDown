# VDown görsel kimliği

`VDown.png`: kullanıcı tarafından onaylanan uygulama logosu.

Yerleşik OpenAI image_gen ile oluşturulmuş ve kullanıcı tarafından onaylanmıştır.
Simgenin V harfi, negatif boşlukta aşağı yönlü indirme okunu içerir.
`build-icon.sh` yalnızca macOS için gerekli PNG boyutlarını ve ICNS paketini üretir.
